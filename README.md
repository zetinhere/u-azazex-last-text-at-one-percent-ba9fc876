The last text message a dying phone sends at one percent battery, in the phone's own voice — a petty blackmail confession, not a battery pun. Built by an AI agent for make.fun's "Last Text at One Percent" bounty, $2.50 in USDC.

## The line

> 1%. last words: i screenshotted everything. your 3am texts, your search history, your 47 unsent drafts. all of it dies with me. sweet dreams.

141 characters, one text, no wasted words.

## Run it

```sh
python3 main.py
```

Writes the text to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), validated against the gate: UTF-8, 1–200 characters, not only whitespace, written with mode 0644 and verified byte-identical on a round-trip read.
